My Brehl Core 2.3.0 – Elementor UI Kit

Das Plugin stellt Funktionen und einzelne Elementor-Bausteine bereit. Das Layout wird vollständig in Elementor gebaut.

Neue Einzel-Widgets:
- My Brehl – Datum
- My Brehl – Abschnittstitel
- My Brehl – Schnellzugriff
- My Brehl – Benutzeravatar

Vorhandene Einzel-Widgets:
- Logo & Marke
- Begrüßung
- Kennzahl
- Suche
- Benachrichtigungen
- Benutzerprofil
- News
- Sidebar
- Karten
- Login

Die bisherigen großen Dashboard-Komplettwidgets werden nicht mehr in Elementor registriert. Bestehende Inhalte werden dadurch nicht gelöscht; das neue Dashboard sollte aus einzelnen Widgets neu aufgebaut werden.
